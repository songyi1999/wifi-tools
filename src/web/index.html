使用教程

一、快速上手（3 步）

  1. 准备：插上 Tenda U2 监听网卡；硬件攻击卡片里点「1 接入网卡」，等状态变绿「已就绪·监听中」（按钮会自动禁用，防止误操作）。
  2. 扫描：点左栏「扫描网卡」列出附近 AP（不断网）；或插上监听网卡后点「2 WSL 扫描」。
  3. 选目标：在扫描结果行点「+加入」，或直接在上面的目标列表文本框里输入 SSID（每行一个）。
  4. 执行：右栏「深度扫描」或硬件攻击里「WSL 扫描」列出目标 → 对目标点「PIN」(PixieDust) 或「抓包」→ 抓到握手包后点「爆破」。

二、各功能区说明

区域作用
目标 SSID 列表批量任务的目标。支持部分匹配（"tp3-204" 能匹配 "3--204"）。点任何任务按钮时会自动同步文本框当前内容（无需先保存）；「保存配置」用于持久化到 config.toml（重启后还在）。
扫描附近网络走 Windows netsh，读缓存 + 4 轮主动触发扫描。不断网，但连接状态下远端弱信号 AP 可能看不到。
硬件攻击（WSL）走 Kali WSL + Tenda U2 监听网卡，能力最强：真监听扫描、定向抓握手包、PixieDust。按钮按 1→2→3 步骤门控，灰的表示前置步骤未完成。需要网卡已插入 USB。
深度扫描右栏按钮。默认先短暂断网再扫（能看到更多弱 AP），扫完自动重连。耗时 = 高级设置里的扫描时长。
抓包 / 爆破「抓包」是 Windows airodump（内置网卡不支持，请用硬件攻击里的抓包）；「爆破」按右栏「爆破范围」下拉框执行——默认「本次抓包（最新会话）」，自动跳过没抓到握手的 cap，可切换全部/指定会话。
命中记录PixieDust 命中自动保存（logs\hits.json / hits.txt，重启不丢），表格含信号强度与「复制密码」按钮。PSK 就是该 WiFi 的密码。
导出密码导出本机已保存的所有 WiFi profile 密码到 logs\passwords_export.txt。
运行全流程无人值守：记住当前网络 → 深度扫描 → 抓包 → 爆破 → 自动恢复原网络。结束状态在右栏显示「网络恢复：是/否」。WPS 攻击请单独用硬件攻击卡片（PixieDust，零失败次数不触发锁定）。

三、硬件攻击（Tenda U2）标准流程

  1. 网卡插 USB（第一次插 Windows 会识别为 U 盘模式，属正常）。
  2. 点「接入网卡」：自动完成 U盘弹出切换 → 接入 WSL → 加载驱动 → 进监听模式。过程中可能弹 UAC 管理员确认，请点「是」。
  3. 点「WSL 扫描」列出 AP（信号彩色排序）。
  4. 对目标行点「抓包」= 定向监听该路由器（默认 120 秒，可在高级设置调大到 600s 守候自然重连）。抓完自动检查握手：抓到会提示「抓到握手包！」，没抓到会如实说明（只有 beacon 跑字典也无效）。
  5. 每次「批量抓包」是一个独立会话（logs\caps\日期时间\），互不混淆；右栏「爆破范围」默认只打最新一次，可切全部。
  6. 对目标行点「PIN」= PixieDust 攻击：对易感固件的路由器秒级算出 PIN，零失败次数、不触发锁定——这是唯一的 WPS 攻击方式（盲试 PIN 会锁死路由器 WPS，已移除）。命中后 PIN/PSK 直接显示。
  7. 抓到握手包 → 右栏「爆破」跑字典。抓包期间目标网络需要有设备产生连接才有握手；可用另一台手机连一次目标 WiFi 触发。
  8. 批量处理：扫描结果行点「加入」把感兴趣的加进目标列表、点「删」排除不感兴趣/信号差的，然后点「批量 PIN（按目标列表）」或「批量 抓包（按目标列表）」自动逐个执行；「停止批量」在当前目标完成后中止。
  9. 没抓到握手想踢线？Tenda U2（aic8800）驱动不支持注入（实测 aireplay --test 0%），无法主动踢设备下线。替代：把「抓包时长」调大到 600s 守候目标设备自然重连（手机 WiFi 会周期性重连）；要主动踢线需换 RTL8812AU 网卡。
  10. 命中结果怎么用：PixieDust 命中后 PIN/PSK 会自动保存到卡片下方的「命中记录」表（也写入 logs\hits.json 和 hits.txt，重启不丢）。PSK 就是该 WiFi 的密码——任意设备连接该 SSID 时输入即可；PIN 用于 WPS 方式连接（很少用）。点行内「复制密码」直接进剪贴板。

四、常见问题

  • 点了按钮没反应？同一时间只允许一个任务，右栏顶部「空闲/运行中」指示当前状态；日志区看实时进度。
  • 接入网卡报"未检测到"？网卡没插或 Windows 侧被占用，重新插拔后再点。
  • Windows 重启 / 网卡重新插拔后？再点一次「接入网卡」即可（伪U盘切换会自动处理，可能再弹一次 UAC）。
  • 断网了？深度扫描会短暂断网并自动恢复；如果显示「网络恢复：否」，点右上「刷新状态」，或手动重连原 WiFi。
  • 抓包文件在哪？logs\caps\ 下，文件名 = SSID_BSSID前4位。字典在 E:\project\wifi-toolkit\dicts\（可点下载按钮补齐）。
  • PIN 一直不中？PixieDust 只对易感固件有效（联发科/瑞昱老固件居多）；未命中会记录在卡片下方。
  • 批量只跑了几个旧目标？旧版 bug，已修：现在点任务前自动同步文本框列表（灰色按钮=前置步骤未完成，按编号 1→2→3 来）。
  • WSL/Windows 自动更新后网卡激活失败（驱动加载失败）？WSL 升级会换内核，旧编译的模块失配。点「接入网卡」会自动从备份重部署匹配模块；若提示需要重编，说明系统又升级了内核版本，需重新编译一次驱动（开发者操作）。
  • 连接命中目标报"无法连接"？多半是信号太弱（命中记录表有信号列，低于 -75dBm 会标红警告）。密码没错，靠近 AP 或把设备移过去再连。
